# Game Theory — From Ground Up

> *An interactive, self-contained HTML course covering the complete foundations of Game Theory — from payoff matrices to Nash Equilibria to iterated strategy tournaments.*

---

## Overview

**Game Theory: From Ground Up** is a single-file interactive primer that teaches the mathematical science of strategic decision-making. No frameworks, no dependencies, no server required — just open the HTML file in any browser.

Built for students, curious minds, and anyone who wants to understand why individual rationality so often leads to collective failure.

---

## Contents

The course is organized into 8 progressive chapters:

| Chapter | Topic |

## Interactive Features

### 🎮 Play the Prisoner's Dilemma
Make your choice — Cooperate or Defect — against a computer opponent. Track cumulative scores across rounds and observe how rational self-interest produces collectively bad outcomes.

### 🔍 Nash Equilibrium Finder
Edit any cell in the 3×3 payoff matrix and click **Find Nash Equilibria**. The tool highlights all pure-strategy Nash Equilibria using the best-response method.

### ⚡ Strategy Tournament Simulator
Run 10-round Iterated Prisoner's Dilemma tournaments. Choose your strategy (Tit-for-Tat, Always Defect, Grim Trigger, Random, Always Cooperate) against a range of opponents. Round-by-round results and totals are displayed in a terminal-style log.

## Key Concepts Covered

- **Payoff Matrix** — reading and constructing normal-form games
- **Dominant Strategy** — when one option is always better regardless of what others do
- **Nash Equilibrium** — stable outcomes where no player wants to deviate unilaterally
- **Minimax Theorem** — von Neumann's solution to zero-sum games
- **Backward Induction** — solving sequential games from the end backward
- **Folk Theorem** — why cooperation is rational in repeated games
- **Mixed Strategy Equilibrium** — randomization as an optimal strategy (e.g., Rock-Paper-Scissors)
- **Signaling** — Spence's model of costly signals in labor markets
